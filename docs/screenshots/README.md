# UI Screenshots

The project README links desktop (1440×900) and mobile (390×844) captures for the Explore home, Library chooser,
G1 Workbench and run, agent detail, analysis, presentation mode, Envelope search, failure diagnosis, race leaderboard,
and World upload.

Captures were made from the locally served UI in mock-planner mode. The G1 run reached the goal in 34.5 simulated
seconds; the Envelope search used 40 runs, diagnosis used 6 runs, and the three-rover race populated its leaderboard
with arrivals at 16.0, 16.3, and 16.6 seconds.
